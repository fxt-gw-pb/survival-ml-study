# 生存机器学习 · 项目自学手册

在线阅读：https://fxt-gw-pb.github.io/survival-ml-study/

- 零基础入门引导：7 步建立直觉，每课另有白话导读、生活类比和难度标记。
- 8 个互动实验（删失、KM、数据划分、风险倍数、LASSO、C-index、ROC、SHAP），数据为教学示意，非项目结果。
- 64 张可翻面的术语卡片，正文术语可点开白话解释。
- 闯关挑战、经验等级、连续学习天数与徽章。
- 30 个学习章节和 30 道自测题。
- 77 张原始 PDF 结果图与高清预览。
- 54 份完整 R 源码，支持搜索、行号跳转和复制。
- 413 份项目材料索引，保留来源、文件哈希与下载入口。
- 学习笔记、进度和答案仅保存在访问者的浏览器，可导出备份。
- 项目代码、历史产物与蒸馏模块之间的差异有逐项说明，未重新训练模型。

本仓库不收录课程媒体文件。两个大 RData 保留在原项目，网页提供其只读对象目录。

## 部署

无构建步骤。GitHub Pages 使用 `main` 分支根目录 `/`，`.nojekyll` 保证静态文件直接发布。

可以用 `python3 -m http.server 8765` 在本地预览，或直接打开 `index.html`。

## 来源与第三方库

原始代码、图表和材料保留小庞统计原作者归属。CoxBoost 为项目附带的第三方依赖，包元数据记录 GPL-2；相应来源文件与文档保留在材料库。Markdown 渲染使用 marked，其 MIT 许可证在 `vendor/marked-LICENSE.md`。

本仓库按既有材料保留结果，并明确方法与版本限制，不添加未执行的实验结论。
